## Why Wivoice?

Voice dictation tools like Wispr Flow are great, but they usually come with a monthly subscription.
Wivoice gives you the same core workflow for free:

1. Press a hotkey.
2. Speak.
3. Your text is typed into whatever app you are using.

Free, with no subscription.

## Features

- **Works in any app**: email, chat, documents, code editors, browsers
- **Global hotkey**: start and stop dictation from anywhere
- **Free**: no paywalls

## Quick start

1. Download `Wivoice.zip` from the Releases page and unzip it.
2. Run `Setup.exe`. On first start the app may ask for microphone permission. Allow it.
3. Click into any text field, press the dictation hotkey, and start talking.
4. Your speech is typed into the field.

## Troubleshooting

**The app does not hear me.**
Check that the correct microphone is selected in your system settings and that Wivoice has microphone permission.

**Text is not typed into my app.**
Some apps run with higher privileges. Try running Wivoice as administrator.

**The hotkey does not work.**
Another program may be using the same shortcut. Close it or choose a different hotkey.
