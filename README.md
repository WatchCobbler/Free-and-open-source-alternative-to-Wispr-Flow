## Why [Wivoice]]?

Voice dictation tools like Wispr Flow are great, but they usually come with a monthly subscription.
[Wivoice]] gives you the same core workflow for free:

1. Press a hotkey.
2. Speak.
3. Your text is typed into whatever app you are using.

No account required. No subscription.

## Quick start

1. Download and install the app for your platform.
2. Launch **[Setup.exe]**. On first start it may ask for microphone permission. Allow it.
3. Pick your hotkey in **Settings** (default: `[e.g. Ctrl + Alt + Space]`).
4. Click into any text field, press the hotkey, and start talking.
5. Press the hotkey again (or release it, depending on your mode) to insert the text.

## Troubleshooting

**The app does not hear me.**
Check that the correct microphone is selected in your system settings and that the app has microphone permission.

**Text is not typed into my app.**
Some apps run with higher privileges. Try running [YourAppName] as administrator, or check that it has accessibility permission (macOS).

**The hotkey does not work.**
Another program may be using the same shortcut. Choose a different one in Settings.
